# HoI4 音乐播放列表编辑器

为《钢铁雄心4》(Hearts of Iron IV) 玩家设计的音乐播放列表管理工具。以图形界面编辑游戏音乐目录下的 `music.asset` 与 `_songs.txt`，支持上传 ogg、设置播放逻辑与音量，保存后游戏内即可生效。

## 功能

- **两级界面**：启动先选择编辑模式——「本地电台编辑」（新建/编辑独立本地电台 MOD）或「已有电台编辑」（直接编辑游戏 mod / 游戏本体 music 文件夹）；编辑中途可随时返回模式选择页切换
- **本地电台 MOD**：一键生成完整的独立电台 MOD（`<电台id>.mod` 注册文件 + `descriptor.mod` + `gfx` 图标 + `interface` 电台界面 + `music` 歌曲目录），产物可直接放入 `文档\Paradox Interactive\Hearts of Iron IV\mod\`，**不修改游戏本体与已有 mod**；生成后自动加载，直接复用全部编辑功能
  - 完整电台界面：自动生成 `music_station_<电台id>.gfx`（sprite 注册）与 `.gui`（faceplate 播放器面板 + stations_entry 电台列表图标），游戏播放器内显示自定义封面与面板
  - **图标裁剪编辑器**：拖拽选区（锁定 152:120 比例）实时预览，自动合成 **304×120 横向两帧**（左=未选中、右=选中高亮，原版 `base_game_album_art.dds` 权威尺寸），支持 jpg / png / webp 等常见格式；更换图标时两帧自动带红/绿边框提示状态
  - 打开已有电台：自动扫描 mod 目录列出已存在的本地电台，一键打开继续编辑
- **开局音效（start_game）**：本地电台模式下可自定义「点击开始游戏 → 加载界面」播放的音效——选择 mp3 / flac / wav 等音频 → 自动转换（44.1kHz / 16bit / 立体声 PCM WAV）→ 裁剪任意区间（限 15 秒，可勾选末尾淡出并设淡出时长）→ 调整音量 → 一键安装进电台 mod（以**追加定义文件** `sound/zz_<电台>_sounds.asset` + `sound/menu/start_game_01.wav` 安装，**不顶掉原版音效**，进入游戏世界的第二段沿用游戏原版）；支持显示当前状态/音效信息与一键禁用
- **选择音乐文件夹**：任意包含音乐文件的目录，自动识别 `music.asset` / `_songs.txt` 以及 mod 自定义命名（如 `xxx_music.asset` + `xxx_songs.txt`）；存在多个文件组时弹出选择框，并记住上次选择
- **歌曲列表**：展示 song name / 文件 / 音量 / 播放逻辑，支持点击表头排序（▲ 升序 / ▼ 倒序）、关键字搜索
- **添加歌曲**：多选 ogg / mp3 / flac 等音频文件 → 自动复制进音乐文件夹（重名自动加 `_2` 后缀，避免覆盖已有文件）→ 自动生成唯一 song name；**支持把音乐文件直接拖入程序窗口添加**
- **音频转换**：mp3 / flac / wav / m4a / aac 一键转换为 ogg 后自动添加（内置 ffmpeg，无需额外安装；后台转换、状态栏显示进度，转换失败单独提示）；转换产物暂存缓存目录（`%TEMP%\hoi4music_cache`），点「保存」时才真正复制进音乐文件夹，关闭程序自动清理缓存
- **播放逻辑**：
  - 预设组合：状态（任意 / 和平 / 战争 / **主菜单**）× 阵营（通用 / 同盟国 / 轴心国 / 共产国际），factor 权重可调；选「主菜单」时自动禁用阵营选择（主菜单音乐由引擎固定播放名为 maintheme 的歌曲）
  - 高级自定义：直接编辑条件文本（如 `has_war = yes`、`has_government = democratic`，每行一条）
- **音量**：每首歌单独设置（0.0 – 2.0）；支持全局默认音量，新添加歌曲自动预填
- **编辑 / 删除**：单选编辑（song name、音量、播放逻辑）；支持 Ctrl/Shift 多选批量删除，多选时编辑按钮自动禁用，删除可一并移除 ogg 文件
- **保存安全**：写回前自动备份原文件为 `.bak`；保存前校验（重复 song name、引用文件缺失等会提示确认）；写回格式为标准格式（每个 music 块之间空一行、规范缩进）
- **修复格式**：工具栏「修复格式」按钮把文件重建为标准格式（注释与 music_station 保留，自动备份 `.bak`），可将其他工具/旧版本生成的错误格式一键修复
- **界面**：所有窗口（主窗口、添加/编辑对话框、默认音量对话框）默认屏幕居中；多显示器下居中于主窗口所在屏幕；小屏自动缩放保护；UTF-8 编码，兼容重音/撇号文件名（如 `La_Liberté.ogg`、`L'Autoritario.ogg`）
- **设置持久化**：全局默认音量、上次使用的文件夹、列表排序状态自动保存到 `%APPDATA%\HoI4MusicEditor\config.json`，下次启动自动恢复并直接加载上次的文件夹
- **设置入口**：一级界面左下角「⚙ 设置」菜单集中提供「全局默认音量」与「关于」（关于显示软件名、版本、作者 BulkCooper 与 QQ 交流群 1076344041）
- **数字签名**：exe 已附加 Authenticode 自签名证书（减少杀软误报；自签名证书不受系统信任，SmartScreen 仍提示未知发布者）
- **音量调节**：滑块 + 实时数值显示（精确到 0.05），彻底避免缩放/主题下的数值显示裁切问题

## 使用方法

1. 运行 `dist\HoI4MusicEditor.exe`（免安装，无需 Python 环境）
2. 启动后进入**模式选择页**，根据你的需求选择一种编辑模式
3. 完成编辑后点「保存」，游戏内即可生效

### 方式一：本地电台编辑（自制独立电台 MOD）

适合想**从零做一个自己的电台**，不碰游戏本体和已有 mod。

1. 在模式选择页点「**新建电台 MOD**」，填写：
   - **电台 ID**：英文/数字（如 `my_radio`，作为 mod 唯一标识）
   - **显示名**：游戏内电台列表显示的名称（支持中文）
   - **目标 mod 目录**：默认自动定位到 `文档\Paradox Interactive\Hearts of Iron IV\mod\`，一般无需修改
2. 生成后自动加载电台，程序会生成完整的电台 MOD（注册文件 + 电台界面 + 封面 + 歌曲目录）
3. 开始添加歌曲、设置播放逻辑与音量（可参考下方[常用操作](#常用操作)）
4. （可选）点「**更换图标**」裁剪电台封面；本地电台模式下可点「**开局音效**」自定义点击「开始游戏」时的音效
5. 点「**保存**」→ 启动游戏，在启动器左侧勾选启用该 mod

已有电台想继续编辑：模式选择页点「**打开电台 MOD**」，可从索引（任意目录）或当前 mod 目录选择已有电台。

### 方式二：已有电台编辑（直接改现有 mod 或游戏本体）

适合直接修改**游戏 mod / 游戏本体 music 文件夹**的现有音乐。

1. 在模式选择页点「**选择 music 文件夹**」，选择游戏音乐目录（例如 HoI4 模组的 `music/` 文件夹；程序会自动识别 `music.asset` / `_songs.txt` 及 mod 自定义命名文件组）
2. 添加 / 编辑 / 删除歌曲，设置播放逻辑与音量
3. 点「**保存**」——原文件自动备份为 `.bak`，之后游戏内即可生效

### 常用操作

- **添加歌曲**：点「添加歌曲」多选 ogg / mp3 / flac 等音频文件（或直接把文件**拖入程序窗口**）；非 ogg 格式会自动后台转换（内置 ffmpeg，无需额外安装），点「保存」时才真正写入音乐文件夹
- **设置播放逻辑**：选中歌曲 → 点「编辑」→ 选择状态（任意 / 和平 / 战争 / 主菜单）× 阵营（通用 / 同盟国 / 轴心国 / 共产国际），或使用高级自定义直接写条件文本（如 `has_war = yes`）
- **调整音量**：选中歌曲 → 点「编辑」调节滑块（0.0 – 2.0）；也可在「⚙ 设置」里设置全局默认音量，新添加歌曲自动预填
- **删除歌曲**：单选或 Ctrl/Shift 多选后点「删除」，可勾选一并移除 ogg 文件
- **修复格式**：若文件由其他工具/旧版本生成导致格式错乱，点工具栏「修复格式」一键重建为标准格式（自动备份 `.bak`）

> 提示：真实游戏目录下保存前若提示「引用的文件不存在」，说明该目录缺少对应的 ogg 文件（通常是仅复制了文本文件），点「是」仍可保存条目。

## 开发与打包

环境要求：Python 3.11+（GUI 仅标准库；音频转换依赖 `imageio-ffmpeg`，图标处理依赖 `Pillow`，均已随 pip 安装并打包进 exe）。

```powershell
# 运行
python app.py

# 单元测试
python -m unittest test_music_lib

# 打包单文件 exe（无控制台窗口，嵌入图标与 logo 资源；使用 spec 以包含 tkinterdnd2 拖放支持）
python -m PyInstaller --noconfirm HoI4MusicEditor.spec

# 签名（自签名证书，已导出 release\HoI4MusicEditor.pfx，密码 hoi4music2026）
$cert = Get-ChildItem Cert:\CurrentUser\My | Where-Object { $_.Subject -like "*HoI4*" } | Select-Object -First 1
Set-AuthenticodeSignature -FilePath dist\HoI4MusicEditor.exe -Certificate $cert

# 产物：dist\HoI4MusicEditor.exe
```

## 文件格式说明

`music.asset` 中每条目：

```
music = {
    name = "my_song"
    file = "my_song.ogg"
    volume = 0.65
}
```

`_songs.txt` 中每条目：

```
music = {
    song = "my_song"
    chance = {
        modifier = {
            factor = 1
            has_war = yes
            has_government = democratic
        }
    }
}
```

## 已知限制

- 窗口居中基于主窗口所在显示器（多显示器时对话框跟随主窗口所在屏幕）
- 高 DPI（150% 以上缩放）下 tkinter 界面由系统缩放，文字可能略模糊但不影响功能
