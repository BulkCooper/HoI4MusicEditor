使用说明
════════════════════════════════════════════════

【这是什么】
一个给《钢铁雄心4》(Hearts of Iron IV) 玩家用的音乐管理工具。
可以往游戏音乐列表里添加/删除歌曲、设置每首歌的播放条件（和平/战争、
阵营）和音量，改完保存，游戏里就能直接生效。不需要安装，双击即可运行。

────────────────────────────────────────────────
【怎么用】
1. 双击运行 HoI4MusicEditor.exe
2. 点击「选择 music 文件夹」，选中游戏音乐目录：X盘:\SteamLibrary\steamapps\common\Hearts of Iron IV\music
   （音乐模组里也有 music 文件夹；里面应有 music.asset 和 _songs.txt，本软件也适配此类模组）
3. 添加歌曲：
   · 点「添加歌曲」，选择音频文件（支持 ogg / mp3 / flac / wav / m4a / aac，可多选）
   · ogg 文件直接复制进音乐文件夹；mp3/flac 等会先自动转换成 ogg 暂存到缓存
     （转换完会提示「保存在缓存中」），点「保存」后才会复制进音乐文件夹
   · 在弹窗里设置：song name（可保持默认）、音量、播放逻辑
   · 提示：未保存就关闭程序，缓存里的转换文件会被自动清理（想保留记得先保存）
4. 点「保存」——原文件会自动备份为 .bak，之后游戏里就能听到新歌了

【定位文件】
选中列表里的歌曲 → 点「打开所在文件夹」（或右键菜单），
会自动打开资源管理器并高亮选中对应的音频文件。

────────────────────────────────────────────────
【播放逻辑怎么选】
· 状态：任意 / 和平 / 战争（什么时候放）
· 阵营：通用 / 同盟国 / 轴心国 / 共产国际（谁的国家放）
· factor：播放权重，越大越容易随机到
· 高级玩家：勾选「高级自定义」可以直接写条件，每行一条，例如：
      has_war = yes
      has_government = democratic

【音量】
· 每首歌单独设置，范围 0.0 ~ 2.0（0.65 为原版标准音量）
· 音量用滑块拖动，旁边实时显示精确数值
· 「全局默认音量」可设置默认值，新添加的歌自动带入

【设置会自动保留】
· 默认音量、上次使用的文件夹、列表排序方式都会自动保存
· 下次打开程序时自动恢复设置，并直接加载上次的文件夹

【删除歌曲】
选中一行 → 「删除选中」→ 选择是否同时删除文件夹里的 ogg 文件

────────────────────────────────────────────────
【注意事项】
· 保存前如果提示「引用的文件不存在」，说明文件夹里缺对应的音频文件，
  点「是」仍可保存（一般不影响）。
· 原文件会在保存时自动备份为 .bak，出问题可以改回原名恢复。
· 如果杀毒软件误报，添加信任即可（程序为开源脚本打包，无任何恶意行为）。
· 系统要求：Windows 10/11，无需安装任何环境。
