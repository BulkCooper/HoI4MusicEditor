# HOI4 音乐电台挂载教程(从零到进游戏)

本教程基于「烈焰升腾:潜龙腾渊电台」(3370537530)的实际结构,手把手教你把一个**新电台**挂进游戏。配套模板见同目录 `radio_template/`。

---

## 一、原理速览(30 秒)

一个电台 = **2 个必需文件 + 3 个可选文件**:

| 文件 | 作用 | 必需? |
|---|---|---|
| `music/<电台>/<名>_music.asset` | 定义歌曲(名字→ogg 文件→音量) | ✅ |
| `music/<电台>/<名>_songs.txt` | 声明电台、把歌挂进播放池 | ✅ |
| `interface/music_station_<名>.gfx` | 图标注册成游戏资源 | 可选(图标) |
| `interface/music_station_<名>.gui` | 电台界面(面板+列表图标) | 可选(图标) |
| `gfx/<名>_album_art.png/dds` | 图标图片(两帧纵向) | 可选(图标) |

**绑定规则(最关键的机制)**:游戏扫描所有加载内容的 `music/` 和 `interface/` 目录——
- `songs.txt` 里 `music_station = "radio_xxx"` 声明电台
- `.gui` 里容器名 `radio_xxx_faceplate` / `radio_xxx_stations_entry` 按**电台名前缀**自动绑定
- 文件名随意,容器名和 sprite 名必须对

---

## 二、准备阶段

### 1. 决定电台名
- 会**原样显示**在游戏播放器里,建议 `radio_xxx` 风格
- **不能与已有电台重名**(`base_music`、`classic`、`radio_qy`、`radio_pla`、`radio_child`、`radio_chi`、`radio_communism`、`radio_redflag` 等),重名=播放池合并
- 本教程用 `radio_my` 做示例,实际用你的名字全局替换

### 2. 准备歌曲
- 格式:**OGG Vorbis**(别的格式游戏不认)
- 转换(例:mp3→ogg,需要 ffmpeg):
  ```powershell
  ffmpeg -i "原曲.mp3" -c:a libvorbis -q:a 5 "我的歌.ogg"
  ```
- 歌名建议用有意义的中文/英文名;asset 里的 `name` 是全局唯一 ID,别和其他 mod 撞

### 3. 准备图标(可选)
- **标准尺寸 `304×120`,横向两帧拼图**:左边一帧=未选中,右边一帧=选中(高亮),每帧 `152×120`(原版 `base_game_album_art.dds` 就是 304×120)
- `noOfFrames = 2` 告诉引擎按两帧切分
- 保存为 png 即可(游戏按内容识别;原版 mod 的 `.dds` 内容实际是 PNG 也能加载)。正式发布建议转 DDS(DXT5)

## 三、创建电台文件

在你选定的 mod 根目录下建这些文件(模板见 `radio_template/`,照着改):

### ① `music/radio_my/radio_my_music.asset`

```clausewitz
music = {
	name = "示例歌曲一"
	file = "示例歌曲一.ogg"      # 相对本文件所在目录
	volume = 0.65                # 0~1
}
```
每首歌一个块,`file` 必须和同目录的 ogg 文件名一致。

### ② `music/radio_my/radio_my_songs.txt`

```clausewitz
music_station = "radio_my"

music = {
	song = "示例歌曲一"
	chance = {
		modifier = {
			factor = 1            # 播放权重,可加任意条件
		}
	}
}

# 条件示例:只在战争时计入权重
music = {
	song = "示例歌曲二"
	chance = {
		modifier = {
			factor = 2
			has_war = yes
		}
	}
}
```

### ③ `interface/music_station_radio_my.gfx`(图标用)

```clausewitz
spriteTypes = {
	spriteType = {
		name = "GFX_radio_my_album_art"
		texturefile = "gfx/radio_my_album_art.png"   # 相对 mod 根目录
		noOfFrames = 2
	}
}
```

### ④ `interface/music_station_radio_my.gui`(图标用)

```clausewitz
guiTypes = {
	containerWindowType = {
		name = "radio_my_faceplate"            # ← 电台名前缀,绑定关键
		position = { x = 0 y = 0 }
		size = { width = 590 height = 46 }
		iconType = { name = "musicplayer_header_bg"
			spriteType = "GFX_musicplayer_header_bg"
			position = { x = 0 y = 0 } alwaystransparent = yes }
		instantTextboxType = { name = "track_name"
			position = { x = 72 y = 15 } font = "VCR02_14"
			text = "track name here" maxWidth = 450 maxHeight = 25
			format = center }
		buttonType = { name = "prev_button"
			position = { x = 220 y = 12 }
			quadTextureSprite = "GFX_musicplayer_previous_button"
			clicksound = click_close pdx_tooltip = "MUSICPLAYER_PREV" }
		buttonType = { name = "play_button"
			position = { x = 263 y = 10 }
			quadTextureSprite = "GFX_musicplayer_play_pause_button"
			clicksound = click_close }
		buttonType = { name = "next_button"
			position = { x = 336 y = 10 }
			quadTextureSprite = "GFX_musicplayer_next_button"
			clicksound = click_close pdx_tooltip = "MUSICPLAYER_NEXT" }
	}
	containerWindowType = {
		name = "radio_my_stations_entry"        # ← 电台列表图标按钮
		size = { width = 162 height = 130 }
		checkBoxType = {
			name = "select_station_button"
			position = { x = 0 y = 0 }
			quadTextureSprite = "GFX_radio_my_album_art"
			clicksound = decisions_ui_button
		}
	}
}
```
> 精简版只放 `radio_my_stations_entry` 就能有列表图标;完整面板照模板文件抄。
> 注意:stations_entry 的 `size = 162×130` 是**容器逻辑尺寸**(与 radio_qy、原版一致),不是图片尺寸;图标图片按像素显示 152×120。

### ⑤ `gfx/radio_my_album_art.png`(图标用)
两帧拼图,见准备阶段第 3 条。

## 四、挂载到游戏(二选一)

### 方式 A:并入现有电台 mod(最快,不推荐)

把上面 5 个文件按目录结构合并进目标 mod,例如:

```
SteamLibrary/steamapps/workshop/content/394360/3370537530/
├── music/radio_my/...      ← 新增
├── gfx/radio_my_album_art.png
└── interface/music_station_radio_my.gui/.gfx
```

⚠️ **缺点**:创意工坊文件会被 Steam 校验,**游戏更新或校验完整性时你的文件可能被删**。

### 方式 B:独立本地 mod(推荐)

**第 1 步**:把 `radio_template/` 整个复制为本地 mod 目录:

```
C:/Users/BulkCooper/Documents/Paradox Interactive/Hearts of Iron IV/mod/radio_my/
├── music/radio_my/...
├── gfx/...
└── interface/...
```

**第 2 步**:在 `mod/` 目录下创建注册文件 `radio_my.mod`(与 mod 目录同级):

```
name="我的电台"
path="C:/Users/BulkCooper/Documents/Paradox Interactive/Hearts of Iron IV/mod/radio_my"
supported_version="1.19.*"
tags={
	"Sound"
}
```

**第 3 步**:启动器会把它识别为"本地 mod",勾选启用即可(见第五节)。

> 💡 如果你还有独立版权/不想依赖创意工坊,方式 B 也是发布给朋友的正确姿势——打包 `radio_my/` 目录 + `.mod` 文件发给他们,放进同样的 `mod/` 目录。

## 五、在启动器里启用(最容易卡住的一步)

HOI4 的 mod 启用不是"放进去就行",必须在 Paradox 启动器里勾选:

1. 打开游戏 → Paradox 启动器(launcher)
2. 左侧 **Playsets**(游戏集)→ 选择/新建一个 playset
3. **Mods** 列表里找到你的电台,勾选 ✅
4. 点 **Play** 启动

⚠️ **你机器上的现状**:之前查过 `launcher-v2.sqlite`,`Initial playset` 里 14 个 mod **全部是未启用状态**(`enabled=0`),`dlc_load.json` 的 `enabled_mods` 为空——也就是说**现在进游戏,一个 mod 都不会加载**。记得勾选。
> 方式 B 的本地 mod 首次出现可能需要**重启启动器**才显示。

---

## 六、进游戏验证

1. 主菜单右下角打开**音乐播放器**(music player)
2. 电台列表(stations)里应出现你的新电台
3. 切换到它 → 随机播放歌曲;点图标可切回其他电台
4. 条件曲目验证:开战后 `has_war = yes` 的歌才会进权重池

**没生效时按这个顺序排查**(前两条覆盖 90% 情况):

| 现象 | 原因 | 解决 |
|---|---|---|
| 电台完全没出现 | mod 没启用 | 回第五节勾选 |
| 电台没出现 | 文件放错目录/没在 mod 内 | 检查路径,见第四节 |
| 电台在,点播放没声 | ogg 格式不对或文件名不匹配 | 转 OGG;核对 asset 的 `file` 与 `name` |
| 电台在,歌不响且日志报错 | 歌曲 name 与其他 mod 重名被覆盖 | 改名 |
| 图标是默认的 | 没做 ③④⑤ 或 sprite 名/路径错 | 核对 `.gfx` 的 texturefile 路径 |
| 图标黑块 | png/dds 路径错或尺寸异常 | 核对路径与两帧尺寸 |

**看日志**:`C:/Users/BulkCooper/Documents/Paradox Interactive/Hearts of Iron IV/logs/game.log`(或 `error.log`),搜你的电台名/歌曲名。

---

## 七、速查卡

- 电台名唯一;歌曲 name 全局唯一;`file` 指向同目录 ogg
- 容器名 `电台名_faceplate` / `电台名_stations_entry`;文件名随意
- 音频只认 OGG Vorbis;图标 304×120 横向两帧(每帧 152×120);`supported_version` 别填太旧
- 直接改创意工坊目录会被 Steam 还原 → 用本地 mod
- mod 必须在启动器 playset 里勾选才加载
