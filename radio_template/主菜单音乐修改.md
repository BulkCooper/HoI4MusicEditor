# HOI4 主菜单音乐(maintheme)修改指南

记录**游戏启动进主菜单时播放的背景音乐**如何定位与编辑。基于本机 1.19.* 游戏本体实测。

> ⚠️ 先分清两件事(经常混):
> - **主菜单音乐** = 音乐(music 系统,`music/` 目录)——本文主题,引擎找名为 `maintheme` 的歌
> - **开局音效** = 音效(sound 系统,`sound/sound.asset` 的 `start_game_01/02`)——见《start_game音效修改.md》
> 两者是**完全独立的两个子系统**,别互相找文件。

---

## 一、主菜单音乐是什么

游戏启动 → Paradox 启动器 → 进入游戏主菜单,此时背景音乐由引擎播放名为 **`maintheme`** 的歌曲(`error.log` 的 `Could not find music named maintheme` 就是它没找到时的报错)。

引擎行为:
- **有 `maintheme`**:主菜单固定播它
- **没有**:报错,然后从音乐池随机选一首(所以你之前听到的都是随机的 DLC 歌)

## 二、机制:三个环节缺一不可

一个能播的 `maintheme` = ① 播放池声明 + ② 音频映射 + ③ 音频文件,缺任何一个都报 `Could not find music named maintheme`。

| 环节 | 文件 | 内容 | 本机当前值 |
|---|---|---|---|
| ① 播放池声明 | `music/_songs.txt` | `song = "maintheme"` | ✅ L5, factor 0.5 |
| ② 音频映射 | `music/music.asset` | `name = "maintheme"` → `file = "xxx.ogg"` | ✅ L4–5 → `hoi4mainthemeallies.ogg` |
| ③ 音频文件 | `music/<file 指定的名字>` | 真 OGG Vorbis | ✅ `music/hoi4mainthemeallies.ogg`(12MB,文件头 `OggS`) |

**实测结论**:定义写好但 ③ 文件没放(或格式不对)时,② 注册失败 → 引擎仍报"找不到 maintheme"。改完必须三步都齐。

## 三、本机当前状态(2026-08-11 参考)

本体 `music/` 目录 = 完整原版音乐集(27 个 ogg)+ 你加的 `maintheme` 定义:

```
music/
├── _songs.txt          # 原版列表 + song = "maintheme"
├── music.asset         # 原版列表 + maintheme → hoi4mainthemeallies.ogg
├── hoi4mainthemeallies.ogg
├── general_peace_*.ogg / axis_war_*.ogg / ...   (27 首原版)
├── 太空电梯.ogg / 无人智胜进行曲-李旭昊.ogg / 祖国不会忘记-黄鹭.ogg   ← 孤儿文件(无定义引用,不播)
├── hoi2/  hoi3/        # classic 电台
└── *.bak               # 改动前备份
```

## 四、编辑方法

### 方式 A:直接改本体(简单,会被还原)

1. 把你的音频转成 **OGG Vorbis**(见五),命名如 `my_maintheme.ogg`,放进 `music/`
2. 编辑 `music/music.asset`:`maintheme` 块的 `file` 改为 `"my_maintheme.ogg"`
3. `music/_songs.txt` 保持 `song = "maintheme"` 不动
4. 重启游戏验证

- ✅ 最直接
- ❌ 游戏更新 / 「验证游戏文件完整性」会还原本体(`.bak` 也会丢)
- ❌ 无法随 mod 分发

### 方式 B:本地 mod(推荐)

音乐系统是**条目合并、同名覆盖**(与音效 `sound.asset` 的整文件替换不同),mod 里用**自定义文件名**追加定义即可,原版不动。

目录结构(放 `Documents/Paradox Interactive/Hearts of Iron IV/mod/`):

```
my_maintheme_mod/
├── descriptor.mod
└── music/
    ├── zz_my_maintheme.asset        # ② 音频映射(自定义文件名,不冲突)
    ├── zz_my_maintheme_songs.txt    # ① 播放池声明
    └── my_maintheme.ogg             # ③ 音频文件
```

`descriptor.mod`:

```
name="主菜单音乐替换"
supported_version="1.19.*"
tags={
	"Sound"
}
path="mod/my_maintheme_mod"
```

`zz_my_maintheme.asset`:

```clausewitz
music = {
	name = "maintheme"
	file = "my_maintheme.ogg"
	volume = 0.65
}
```

`zz_my_maintheme_songs.txt`:

```clausewitz
music_station = "base_music"

music = {
	song = "maintheme"
	chance = {
		modifier = {
			factor = 100
		}
	}
}
```

> 细节:
> - `file` 是**相对该 asset 文件所在目录**的路径:asset 放 `music/` 根目录时 `file = "my_maintheme.ogg"` 指 `music/my_maintheme.ogg`;asset 放 `music/xxx/` 子目录时指向 `music/xxx/`。
> - `name = "maintheme"` 与本体同名 → mod 后加载覆盖,主菜单播你的文件。
> - `factor` 只影响**游戏内自动播放池**的权重(调大 100 让游戏内也更常播);**主菜单是引擎写死找 maintheme,与权重无关**。

### ⚠️ 为什么不能换名字?

引擎主菜单只找名为 `maintheme` 的歌。换成 `my_song` 之类 → 主菜单不播。想"加一首新歌进池子"可以随便起名,但**覆盖主菜单音乐必须叫 `maintheme`**。

## 五、音频规格

- **格式**:OGG Vorbis(游戏只认 ogg 音乐;mp3/wav 不行)
- **采样率**:44.1kHz。不是 44.1kHz 会刷 `For best performance and quality music files should be in 44.1kHz (歌名)` 警告,可能音调/速度异常
- **别做假 ogg**:把 mp3 直接改扩展名 `.ogg` 引擎解析失败,该歌曲注册不上(表现为 `Could not find music named maintheme` 或池子里没这首歌)。验证:用十六进制看文件头,真 ogg 以 `OggS` 开头
- 转换示例(ffmpeg):
  ```powershell
  ffmpeg -i "原曲.mp3" -c:a libvorbis -q:a 5 "my_maintheme.ogg"
  ```

## 六、验证与排查

1. 重启游戏,进主菜单听是否播放目标歌
2. 看 `Documents/Paradox Interactive/Hearts of Iron IV/logs/error.log`:
   - `Could not find music named maintheme` → ①②③ 三步没齐(最常见:③ 文件没放/是假 ogg)
   - `For best performance... 44.1kHz (歌名)` → 该歌采样率不对
3. 进入游戏世界后主菜单音乐停止属正常(进入游戏后播游戏内场景音乐)

## 七、踩坑记录(本机实测)

**案例 1:定义齐了但文件晚放 → 报错**
`music.asset`/`_songs.txt` 先改成 maintheme,但 `hoi4mainthemeallies.ogg` 是 2 小时后才放进 `music/`。期间启动,`error.log` 三次报 `Could not find music named maintheme`(11:02/11:03/11:07),主菜单随机播池子里的歌。文件放好后未再验证(下次启动应正常)。

**案例 2:sound.asset 与 music 别混**
往 mod 里加音效时定义文件叫了 `sound/sound.asset` → 原版 799 个音效全灭(整文件替换语义)。音乐文件无此问题(条目合并),但**音效定义文件务必用自定义文件名**,详见《开局音效故障排查.md》。

**案例 3:孤儿文件**
`music/` 里的 ogg 若没有 asset 定义 + songs 声明,永远不会播放(如本体的三首中文歌)。

## 八、快速自查清单

- [ ] ① `*_songs.txt` 里有 `song = "maintheme"`
- [ ] ② `*.asset` 里有 `name = "maintheme"` + `file = "xxx.ogg"`
- [ ] ③ `xxx.ogg` 真实存在、文件头是 `OggS`、44.1kHz
- [ ] 若用 mod:定义文件是自定义文件名(不是 `sound.asset`;音乐类无此限制但保持一致习惯)
- [ ] 重启游戏后 error.log 无 `Could not find music named maintheme`
