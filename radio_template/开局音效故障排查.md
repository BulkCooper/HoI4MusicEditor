# 开局音效(start_game)无法加载——排查与修复记录

> 日期:2026-08-11 ｜ 对象:本地 mod `Test_Radio`(C:\Users\BulkCooper\Documents\Paradox Interactive\Hearts of Iron IV\mod\Test_Radio)
> 现象:开局(点击开始游戏、进入游戏世界)音效无声,且**整个游戏的音效都消失**(点击、悬停、事件弹窗全部没声音)

## 一、日志定位

游戏日志:`C:\Users\BulkCooper\Documents\Paradox Interactive\Hearts of Iron IV\logs\error.log`

```
[10:48:58][no_game_date][pdx_audio.cpp:337]: Missing sound: cavalry_entity_move_01        ← 原版音效集体丢失(共 911 条)
[10:48:58][no_game_date][pdx_audio.cpp:337]: Missing sound: ui_menu_over / click_default / event_popup_01
[10:49:24][1936.01.01.12][pdx_audio.cpp:337]: Missing sound: start_game_02                  ← 开局无声的直接原因
```

关键观察:911 条 `Missing sound` 的时间戳是 **10:48:58**(启动时),而 `Test_Radio/sound/sound.asset` 的修改时间是 **10:48:04**——放进去后第一次启动就全灭。

## 二、问题清单

### 问题 1(主因):mod 里的定义文件叫了 `sound.asset` → 整文件替换,原版 799 个音效全灭

- **现象**:911 条 `Missing sound`,连 `ui_menu_over`、`click_default` 这种高频 UI 音效都丢
- **根因**:HOI4 对 `sound/sound.asset` 是**整文件替换**语义——不像 `events/`、`decisions/` 那样按条目合并。mod 里只要存在同名 `sound/sound.asset`,原版 799 个 sound 定义会被**整个顶掉**,只剩 mod 里写的几个。本次 mod 的 `sound.asset` 只有 101 字节、只定义了 `start_game_01`
- **证据**:本体 `sound/sound.asset` L2094 明确有 `cavalry_entity_move_01` 定义(文件也存在),却照样报 Missing——说明本体的定义压根没被加载
- **修复**:定义文件改名 **`zz_test_radio_sounds.asset`**(自定义文件名,不与原版冲突),游戏会把它当作**追加定义**:原版 799 个音效保留,同名 sound 被覆盖

### 问题 2:开局真正播的是 `start_game_02`,不是 `start_game_01`

- **现象**:进入游戏世界那一刻(时间戳 `1936.01.01.12`)报 `Missing sound: start_game_02`
- **根因**:开局音效有两个,代码分两处播放——点击「开始游戏」播 `start_game_01`,读条完成进入游戏世界**再播一次 `start_game_02`**。mod 只定义了 01,02 缺失 → 开局无声
- **修复**:mod 定义里补上 `start_game_02` 块,并在 `sound/menu/` 放入对应的 wav

### 问题 3(顺带提醒):`start_game_01` 的音量是 `volume = 0.1`

原版定义里 `start_game_01` 音量仅 10%,`start_game_02` 无此字段(默认 100%)。换音频时按自己的响度调整,别以为没生效。

## 四、教训(写给自己/以后改游戏音效)

1. **`sound/sound.asset` 是整文件替换**,不是合并。mod 里要加音效定义,文件**绝不能叫 `sound.asset`**,用自定义文件名(如 `zz_xxx.asset`)追加。
2. **开局音效有两个**:`start_game_01`(点击开始游戏)+ `start_game_02`(进入游戏世界),**两个都要定义/替换**,只改 01 开局仍然无声。
3. **改名字没用**:引擎代码写死只查找 `start_game_01` / `start_game_02`,换新名字不会被播。
4. **排查顺序**:先看 `logs/error.log` 搜 `Missing sound`——几百条=顶掉了原版;单条 `Missing sound: start_game_02`=定义缺失或 wav 没放。
5. **音频规格**:WAV(PCM)/44.1kHz/16bit;非 44.1kHz 会刷 `For best performance... 44.1kHz` 警告。

## 五、验证步骤

1. Paradox 启动器确认「Test Radio测试电台」仍勾选启用。
2. 重启游戏,点击「开始游戏」→ 应听到自定义的 `start_game_01`。
3. 读条完成进入游戏世界 → 应听到 `start_game_02`(目前是原版占位)。
4. 顺手确认普通音效恢复:主菜单悬停、点击、事件弹窗都有声。
5. 查看最新 `error.log`:不应再出现 `Missing sound: start_game_02`,也不应有成片的 `Missing sound`。
