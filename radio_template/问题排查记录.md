## 二、问题清单

### 问题 1(主因):gui 引用了不存在的 sprite 和字体 → 电台面板(faceplate)渲染失败

- **现象**:游戏内电台图标/顶部面板显示异常
- **根因**:`music_station_Test_Radio.gui` 是从「烈焰升腾:潜龙腾渊电台」(3370537530)的 `music_station_radioqy.gui` 复制改名的,但里面带了 **radioqy 自定义的资源**,独立 mod 里不存在:
  - `iconType` 引用了 `GFX_musicplayer_head` —— 经全库检索,该 sprite **在游戏本体和 3370537530 里均未定义**(原作者自己的 bug)
  - 字体 `VCR02_14` / `VCR02_12` —— radioqy mod 自定义字体,Test_Radio 没有
- **报错**:`Could not find sprite type [GFX_musicplayer_head]`、`No font with name VCR02_14`
- **正确做法**:只引用**游戏原版自带**资源。原版 `music_station_base.gui` 的 faceplate:
  - 没有 `musicplayer_head` 元素
  - 字体用 `hoi_20b`(track_name)、`hoi_18b`(时间显示)
- **修复**:
  - 删除 `musicplayer_head` 的 `iconType`
  - 字体改为 `hoi_20b` / `hoi_18b`

### 问题 2:`Test_Radio.mod` 的 supported_version 格式无效

- **现象**:启动时 mod 版本校验报错
- **根因**:`supported_version="1.*"` 不是合法格式(与 `ugc_3351917033.mod` 等同样报错)
- **修复**:改为 `supported_version="1.19.*"`(与当前 TFR 版本线一致)

### 问题 3:歌曲 name 与游戏本体重名 → 该歌曲被忽略

- **现象**:`Music with name '无人智胜进行曲_李旭昊' already added`
- **根因**:Test_Radio 的 `Test_Radio_music.asset` 里 `name = "无人智胜进行曲_李旭昊"`,与**游戏本体** `Hearts of Iron IV\music\music.asset` 注册的歌**同名**。歌曲 name 是全局唯一 ID,后加载的(Test_Radio)这份被忽略
- **修复**:Test_Radio 内改为 `无人智胜进行曲_李旭昊_TR`(asset 与 songs.txt 同步)

## 四、教训(写给自己/以后做电台 mod)

1. **复制其它 mod 的 gui 时,只抄结构,资源引用必须换成游戏原版自带的**(sprite 查本体 `gfx/interface/topbar/musicplayer/`、字体用 `hoi_*` 系列)。
2. **歌曲 `name` 全局唯一**:和任何已加载内容(本体、DLC、其它 mod)重名都会被忽略。
3. **`supported_version` 格式**:必须形如 `"1.19.*"`,不能写 `"1.*"`。
4. **图标图片标准**:304×120,横向两帧(左=未选中,右=选中),每帧 152×120;stations_entry 容器 size 162×130 是逻辑尺寸,与图片尺寸无关。
5. **排查顺序**:先看 `logs/error.log`,搜自己的电台名/歌曲名/gui 文件名。

## 五、验证步骤

1. Paradox 启动器确认「Test Radio测试电台」已勾选启用
2. 重启游戏,主菜单右下角打开音乐播放器
3. 电台列表出现 `Test_Radio` → 切换,检查顶部面板与图标
4. 若仍异常,查看最新 `error.log` 是否还有 `Could not find sprite` / `No font` 报错
